# 试运行计划

试运行 3-5 个交易日。目标是验证提醒是否少而准，报告是否能帮助减少错误。

## 试运行只开启

- 08:45 盘前计划。
- 10:00 今日行动咨询。
- P0 风控提醒。
- 15:30 收盘复盘。

先不要开启太多提醒，避免噪音和冲动交易。

## 暂不开启

- 高频盘中机会提醒。
- 多渠道重复推送。
- 自动生成买入候选列表。
- 根据社媒热度触发交易建议。

## 验收标准

- 没有计划内买点时，报告明确写“没有”。
- 风控提醒及时且不重复。
- 买入相关输出都有价格条件、仓位上限、止损/失效条件。
- 执行 Agent 没有修改核心规则。
- 用户没有因为提醒增加冲动交易。
