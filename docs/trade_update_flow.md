# 交易更新流程

本流程只记录手动交易，不执行交易。

## 用户输入

```text
日期：
标的：
代码：
市场：
动作：
价格：
数量：
金额：
仓位类型：
买入/卖出理由：
止损/失效条件：
目标/退出条件：
是否遵守规则：
情绪：
结果：
备注：
```

## 执行 Agent 输出

1. 生成交易日志草稿。
2. 标注是否缺少关键字段。
3. 标注是否违反短线仓、亏损补仓、社媒跟买等纪律。
4. 等待用户或策略 Agent/Codex 确认后再归档。

## 禁止

- 不自动提交真实交易。
- 不登录账户核验成交。
- 不保存密码或验证码。
- 不因为记录了一笔交易就自动更新核心规则。
