# 运行手册

## 每日启动

1. 检查 `portfolio.yaml` 是否为最新。
2. 检查 `watchlist.yaml` 是否有计划内条件。
3. 生成盘前计划。
4. 明确今天是否存在计划内动作；没有就写“没有”。

## 盘中处理

- P0 风控优先。
- 机会提醒必须有价格条件、仓位上限、止损/失效条件。
- 社媒只做情绪雷达。
- 不自动交易，不直接下单。

## 收盘处理

1. 记录当天手动执行的操作。
2. 检查是否遵守规则。
3. 记录情绪和偏离。
4. 更新明日观察条件。

## 周度处理

- 检查资产比例。
- 检查短线仓是否超限。
- 检查是否发生亏损补仓或追涨。
- 检查规则是否需要由策略 Agent/Codex 调整。
