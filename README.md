# 个人投资顾问系统

`investment-advisor` 是一个本地个人投资顾问项目，用来记录投资档案、资产结构、持仓、观察池、信息源、交易纪律、每日计划和复盘。

这个项目的第一目标不是提高交易频率，而是减少错误、控制亏损、守住纪律。

## 核心边界

- 不自动交易。
- 不直接下单。
- 不登录券商、银行、支付账户。
- 不保存密码、验证码、交易口令。
- 只辅助决策，所有交易必须由本人确认并手动执行。
- 没有价格条件、仓位上限、止损/失效条件时，不允许生成买入建议。
- 没有计划内买点时，必须明确写“没有”，不能凑推荐。

## 每日工作流

1. 08:45 盘前计划：确认市场环境、持仓风险、观察池条件，明确今天是否有计划内动作。
2. 10:00 今日行动咨询：只处理已经进入规则的标的；没有计划内买点就写“没有”。
3. 盘中扫描：优先风控，其次才是机会提醒；社媒只作为情绪雷达。
4. 14:05 基金/场外信息检查：检查基金、公告、申赎或估值变化，不做冲动决策。
5. 15:30 收盘复盘：记录执行、偏离、情绪、风险和明日条件。
6. 20:30 晚间摘要：只保留重要变化，避免信息噪音。
7. 周日 20:30 周度资产配置复盘：检查资产比例、现金流、仓位边界和纪律执行。

## 使用原则

- 盘中只控风险，盘后做决策。
- 长期仓、机会仓、短线仓必须分开记录，不能互相挪用理由。
- 短线票亏损后不能改成长线。
- 亏损短线票不加仓。
- 社媒、公众号、小红书、社群永远只做情绪雷达，不能直接作为买入依据。
- 所有买入建议必须包含价格条件、仓位上限、止损/失效条件。
- 选票和研究必须遵守 `research_framework.md`，不猜“主力意图”，只分析可观察证据。
- 所有输出都必须提醒：最终执行由本人手动确认。
